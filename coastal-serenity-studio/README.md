# The Coastal Serenity Studio — concept demo

This is a **sendable first demo** for your mum and sister. It is intentionally a complete visual direction rather than a finished business website: the logo, photos, exact prices, social handles and final wording can all be swapped as the brand develops.

## Run it locally

```bash
cd coastal-serenity-studio
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## What is placeholder content?

- The current wordmark is a temporary text logo.
- The hero image is a neutral placeholder; no client photography is used in this demo.
- The colour palette and “coastal serenity” direction are a visual concept.
- The Richards Bay location and treatment list are supplied for this demo; prices, exact address, opening hours, contact number and social links still need confirming.
- Booking and social links are intentionally placeholders until the studio has its own details.

## Easy next steps

1. Choose the brand direction with your mum and sister.
2. Replace the wordmark with the designed logo.
3. Add their preferred portraits and treatment photos to `public/images/`.
4. Confirm the service menu, prices, address, opening hours and booking process.
5. Replace the temporary social links and add a real booking system if needed.

The page is built with the same Next.js and TypeScript approach you have been learning in the main project, but it is isolated in its own folder so it can be changed safely.
